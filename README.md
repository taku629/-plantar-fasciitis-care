# 足底腱膜炎ケア手帳 (Plantar Fasciitis Care Notebook)

足底腱膜炎で悩む人向けの、スマホのブラウザだけで使える記録・リハビリ支援PWAです。

## 機能

- **朝イチの痛み記録**: 足底腱膜炎の指標「起きて最初の一歩の痛み」を0-10で記録
- **リハビリ体操ガイド+タイマー**: 足底筋膜ストレッチ、ふくらはぎ・ヒラメ筋ストレッチ、タオルつまみ、ヒールレイズ、足裏アイシング
- **活動記録**: 歩数・立ち時間・履物・メモ
- **相関グラフ**: 痛みの推移と歩数・体操実施の重ね合わせ(14日/30日)
- **週間レポート**: 診察時に見せられる集計(印刷/PDF保存/テキストコピー)
- **バックアップ**: JSONエクスポート/インポート

## 特徴

- ログイン不要・データは端末内(localStorage)にのみ保存。外部送信なし
- PWA対応: Android Chrome で「ホーム画面に追加」すればアプリとして動作・オフライン利用可
- 高齢者向けの大きめUI(基準18px、最小タップ48px)

## 構成

| ファイル | 役割 |
|---|---|
| `index.html` | SPA本体(ホーム/体操/記録/グラフ/レポート/設定タブ) |
| `app.js` | 状態管理・描画・タイマー・チャート(SVG)生成 |
| `style.css` | モバイル向けスタイル+印刷用スタイル |
| `sw.js` | Service Worker(オフラインキャッシュ) |
| `manifest.webmanifest` | PWAマニフェスト |
| `icons/` | アプリアイコン |

## ローカル実行

```sh
python -m http.server 8000
# → http://localhost:8000
```

## デプロイ

静的ファイルのみのため、任意の静的ホスティング(GitHub Pages, Netlify, devinapps等)にそのまま置けます。HTTPS環境ではService Workerが有効になりオフライン動作します。

※このアプリは医療機器ではありません。症状の記録と自己管理を助けるものです。
